Scientific limitation
This is a real, trainable, miniature CNN built for illustration, not a reliable commercial cat detector. The small teaching set contains variations of one cat photo and five unrelated images. Accuracy is measured only on related classroom examples; it is not independent test accuracy. Try the brightness/noise sliders to demonstrate uncertainty. Cat photo: scikit-image “chelsea”; other images: scikit-image sample photos.
Implementation principle informed by public educational examples: micrograd (backpropagation) and TensorFlow.js examples. All learning math runs locally in this page. English captions with Arabic teaching notes. No API, uploads, sign-in or network needed.
