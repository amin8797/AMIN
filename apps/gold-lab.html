PRESENTER'S NOTEBOOK

How to make this a memorable lesson

01 / Start with the trend

Ask students whether a strong upward historical trend proves that tomorrow's price must rise. It does not.

02 / Run the backtest

Click PLAY, then switch between AR(5), Random Walk, and Ridge(20). Watch prediction errors during sharp movements. Change validation vs test metrics to discuss model selection and overfitting.

03 / Rotate the market in 3D

Explain: volatility captures how unstable recent returns were. A 3D plot reveals heterogeneity, but it is a visualization, not proof of causality.

04 / The R versus Python question

"إذا استعملنا نفس البيانات ونفس النموذج ونفس طريقة التقييم في R وPython، هل لغة البرمجة وحدها تجعل التنبؤ أدق؟" لا، المعيار هو المنهجية والتنفيذ والبيانات.
