How to use the demonstration

Select an image orientation and a filter from the dropdown. Hover over a pixel or feature-map cell to inspect the value. The filter is deliberately hand-designed: this visual explains the operation, not a trained CNN.

Scientific interpretation

The output is a feature map produced by sliding the kernel over the image. Stronger responses indicate a stronger match for this particular handcrafted filter. These diagrams contain no real-world inspection data and do not report classifier accuracy.
