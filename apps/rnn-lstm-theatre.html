MEMORY EQUATION, IN PLAIN ENGLISH

cₜ = fₜ × cₜ₋₁ + iₜ × gₜ
hₜ = oₜ × tanh(cₜ)
Forget · keep or reduce the past

A higher forget gate keeps a greater fraction of the old cell state.

Input · write new information

The input gate scales candidate memory, which can be positive or negative.

Output · share information

The output gate controls the hidden state exposed to the next step.

IMPORTANT SCIENTIFIC DISTINCTION

This is a controlled mathematical memory experiment, not a benchmark comparing trained networks. Real RNNs and LSTMs learn their weights and may behave differently. LSTMs help with long-range dependencies, but do not solve every prediction problem.

HOW THIS MODEL WAS BUILT

  1. Generate 108 illustrative monthly sales observations with trend, seasonality and noise.
  2. Fit normalization using training data only.
  3. Build 12-month input windows and train an 8-unit PyTorch LSTM.
  4. Predict each next month using only the previous 12 observed values.
  5. Evaluate on the last 30 months, then compare with a naïve baseline.
Scientific caution: These are simulated teaching data, not bank or company records. The LSTM is actually trained, but this demonstration does not establish real-world forecasting performance. Different data may favor the naïve model.

ONE-MINUTE SUMMARY

CNN: learns patterns in images and other structured data.

RNN: processes a sequence with a recurrent hidden state.

LSTM: is an RNN with gated cell memory.

Evaluation: always test on future data and compare with simple baselines.
