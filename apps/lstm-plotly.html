How to use the demonstration

Move the slider to select a different target month. The thick blue line marks the previous 12 observed months that could be used as one input sequence. The green diamond is the next observed value; the red cross is the seasonal-naive forecast from 12 months earlier. No LSTM model is trained in this visual.

Scientific interpretation

The diagram demonstrates how chronological input windows and out-of-sample targets are constructed. The data are synthetic. The seasonal-naive value is a baseline forecast, not a trained LSTM prediction. Do not interpret the displayed demand as real retail transactions.
